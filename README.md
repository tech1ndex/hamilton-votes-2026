# Hamilton Votes 2026

A single-page, non-partisan guide to the 2026 Hamilton, ON municipal election — Mayor and all 15 Ward council races. Browse the 13 mayoral candidates by issue, compare their platforms side by side, or look up who's running in your ward.

Live at **[hamontvotes.ca](https://hamontvotes.ca)**.

Positions are drawn from CBC Hamilton's candidate coverage and the candidates' own campaign material, compiled October 20, 2026. Platforms may change before Election Day, so check each candidate's own site for the latest. This guide does not endorse any candidate.

Voting information: https://www.hamilton.ca/city-council/municipal-election

Static site, no build step — just `index.html`.
